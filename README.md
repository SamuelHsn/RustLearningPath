# Rust Learning Path

Welcome to your personalized Rust learning journey! This learning path is designed specifically for developers with experience in **TypeScript**, **.NET (C#)**, **Java**, and **C**.

## 🎯 Learning Objectives

By the end of this learning path, you will:
- Understand Rust's ownership model and memory safety guarantees
- Write idiomatic Rust code with confidence
- Build real-world applications using Rust
- Leverage your existing programming knowledge to accelerate learning

## 📚 Repository Structure


## 🚀 Getting Started

1. **[Setup Your Environment](setup/installation.md)** - Install Rust and essential tools
2. **[Language Comparison Guide](comparisons/README.md)** - See how Rust relates to languages you know
3. Start with Week 1 Theory, then do Week 1 Practice
4. Progress at your own pace - each week builds on previous concepts

## 💡 Learning Tips

- **Don't rush ownership**: Spend extra time on Week 2 - it's the most important concept
- **Fight the compiler**: Early on, you'll fight the borrow checker. That's normal and part of learning!
- **Compare with what you know**: Use the comparison guide to relate Rust to TypeScript/Java/.NET/C
- **Do the exercises**: Theory without practice won't stick. Try solving exercises before looking for help
- **Build projects**: After Week 4, start a small project to apply what you've learned
